# DimASR 官方最优方案与 Jev 差距（2026-09-23）

目前 Jev 9-shot + shrink 的全量 test RMSE_VA 为 **1.1199**；按同一口径汇总官方成绩，PAI 约 **1.0663**、TeleAI 约 **1.0737**。我们已经接近，但还没有在全量汇总上超过这两个方案。追平 PAI 需要再降低 **0.0536 RMSE，即当前误差的 4.8%**。这是值得尝试的目标，现有结果还不足以保证能够达到。

## 来源与比较口径

依据赛事组织者的最终版 [SemEval-2026 Task 3 官方报告](https://aclanthology.org/2026.semeval-1.452/)：**Table 3** 列出各语料前三名，**Table 6** 列出 Track A / Subtask 1 的全部成绩。这里仅比较我们正在做的 DimASR；不混入其他子任务、Track B 或 dev 分数。

比赛按语料排名，没有公布这里使用的“十语料 micro 总冠军”。README 新增的三支队伍都至少获得一个 ST1 语料第一名，并有完整十语料结果和对应方法论文。PAI 是 Table 6 中覆盖全部十语料的队伍里，按本仓库 micro 口径换算后最好的系统；这不等于它在每个语料都是第一。

换算使用官方报告的四位小数成绩，以及本项目官方 test gold 的标注条目数：

`RMSE_micro = sqrt(sum(N_c * RMSE_c**2) / sum(N_c))`

总计 **16,186** 条标注。权重见下表；不是对十个 RMSE 取算术平均，也不是按文本数加权。由于官方输入分数已经四舍五入，换算结果标为近似值。Jev 的来源是 [test_summary.json](../reports/calibration_20260923/test_summary.json)，协议见 [实验 0005](../logs/0005-st1-supervised-calibration.md)。

## 经过官方结果核实的方案

**PAI — Qwen3-32B LoRA + 联合 V/A 分布适配。**

论文：[PAI at SemEval-2026 Task 3: An LLM and Data Redistribution Adaptation-Based Predictive Strategy for Valence-Arousal Scores](https://aclanthology.org/2026.semeval-1.193/)。官方俄语、鞑靼语、乌克兰语第一；换算 micro 为 **1.0663**。

它先微调 Qwen3-32B，再通过 Sinkhorn 最优传输把预测的二维 V/A 分布适配到训练标签分布，利用两维之间的关联，而不只是分别调整两个均值和尺度。论文 Table 1 的 test 分数与官方报告一致。Table 4 在 dev 上报告，Gaussian 适配换成 Sinkhorn 后，俄语从 1.0628 到 1.0372、鞑靼语从 1.4359 到 1.3535、乌克兰语从 1.1949 到 1.0834。这支持尝试联合标定，但不能把这些 dev 收益直接加到 Jev 的 test 上。

**TeleAI — Qwen2.5-7B LoRA 回归 + 多语言联合训练 + 线性标定。**

论文：[TeleAI at SemEval-2026 Task 3: Large Language Models for Dimensional Aspect-Based Sentiment Analysis](https://aclanthology.org/2026.semeval-1.233/)。官方日语酒店、日语金融、中文笔记本第一；换算 micro 为 **1.0737**。

它用 aspect/text 标记表示输入，对隐藏状态池化后直接回归二维分数，使用有界输出、Huber 损失、R-Drop 和对抗训练，并对输出做线性校准。最值得借鉴的是训练目标直接对齐 V/A 回归，以及跨语言共享训练。论文中的 **0.85 是英语餐厅 dev 成绩**，不能作为全量 test SOTA 填进 README。其方法也说明：领先队伍已经在使用校准，我们不能假设“加上校准”本身就能超越它们。

**ICT-NLP — XLM-RoBERTa-large 多语言联合训练 + 自适应集成。**

论文：[ICT-NLP at SemEval-2026 Task 3: Less Is More — Multilingual Encoder with Joint Training and Adaptive Ensemble for Dimensional Aspect Sentiment Regression](https://aclanthology.org/2026.semeval-1.131/)。官方中文餐厅第一、中文笔记本第二、日语酒店第三；换算 micro 为 **1.1592**。

它不依赖大语言模型或外部语料，使用多语言编码器、有界回归头，以及在 dev 上选择的模型子集集成；最终候选包含不同超参数的七个 XLM-R large 模型。论文 Table 1 与官方结果一致，但其中 **Avg = 1.0886 是跨语料算术平均**，不是我们的 micro。Jev 当前 micro 比它低 **0.0393**，但在中文餐厅等语料仍落后。这表明局部 SOTA 和全局汇总领先需要分开描述，也说明达到竞争水平不一定需要更大的 LLM。

[LogSigma 的论文](https://aclanthology.org/2026.semeval-1.165/)采用语言编码器、双回归头、学习两维损失的不确定性权重和多随机种子集成。它是两个英语语料的官方第一，但 Table 6 只提供这两个语料结果，因此不为它编造十语料汇总。中文金融最佳值直接取自官方报告。

相对 PAI 的净平方误差差额，按 `N_c × (Jev_c² − PAI_c²)` 分解，**俄语和乌克兰语合计占约 78.7%**。这是净差额占比，包含 Jev 在英语笔记本、日语金融、鞑靼语上的优势抵消；不是总误差占比。优先缩小这两个语料的差距，比平均用力更有依据。

这两个语料的 arousal 残差均值约为 **+0.64**，arousal RMSE 约为 **1.14**，说明标定后仍存在偏差与区分能力不足。英语餐厅/笔记本的 valence RMSE 则约为 **1.06 / 1.10**。全量剩余平方误差约 **54.7% 来自 arousal，45.3% 来自 valence**，已经不能把问题全部归因于 arousal 的尺度。

局部结果值得关注：9-shot 标定后的鞑靼语 **1.4903** 低于官方最佳 **1.5294**；另一个固定方案 zero-shot 标定后的英语餐厅 **1.0783** 低于 LogSigma 的 **1.1035**。这些是点估计比较，不能事后把两个方案的 test 最优语料拼成一个新系统。我们也没有参赛队的逐条预测，无法据此声称相对 SOTA 的提升具有统计显著性。

## 能否接近、达到或超过

**接近：已经做到。** 与 PAI 相差 0.0536，与 TeleAI 相差 0.0461；分别需要降低当前 RMSE 的 4.8% 和 4.1%。追平 PAI 对应约 **9.35% 的均方误差降低**，仍是实质性改进，不能理解成几乎没有差距。

**达到：有合理可能，优先验证简单标定还有多少空间。** 我们每语料只用 256 个训练文本组来拟合输出映射，且 V/A 分开处理；PAI 的联合分布适配提供了明确可借鉴的方向。不过我们已有 linear 候选在 dev 上只比 shrink 好约 0.018，没有达到原有 0.02 的选择门槛；直接改用 linear 并没有已知证据足以弥补 test 差距。

**超过：局部点估计已有例子，全量尚无证据。** 当前单维 shrink 主要解决均值和尺度问题，在不裁剪且斜率为正时不能改善维度内排序；当相同 Jev 分数对应不同的真实强度时，简单映射无法恢复丢失的信息。领先系统还利用了完整文本的监督训练。若输出映射收益耗尽，后续提升可能需要增加与方面相关的情绪信息，或训练小型文本回归器。

此外，我们的校准使用额外监督标签，不能称为纯 9-shot 学习；各系统的训练预算也不同。当前 test 已在历史实验中查看过，以上是公开 test 上的研究比较，并非新的官方比赛名次。

## 建议的最小下一步

1. **先复用已有训练预测，增加一个二维 ridge 标定候选。** 用 `(Jev_V, Jev_A)` 同时预测 `(gold_V, gold_A)`，让两维互相提供信息，与当前独立 shrink 比较。沿用现有 grouped train CV 和 dev 选择，翻译组继续放在同一折；few-shot 展示分数保持 gold 原值。先不引入 Sinkhorn 的全套实现。
2. **再单独验证训练样本量。** 保持模型、提示词和标定候选不变，把每语料训练文本组从 256 扩到 1024（不足则用可用部分），只补新训练样本的 API 预测。这样能分清收益来自联合映射还是更多标定数据。重点查看俄语/乌克兰语 arousal 与英语 valence 的 dev 误差；上述 test 偏差不能直接当成修正常数。
3. **如果前两步收益不足，再增加文本信息。** 可以先试少量有明确含义的 aspect 情绪特征配合小回归器；若接受微调，再参考 ICT-NLP 的多语言编码器回归路线。没有必要一开始复制大模型微调、对抗训练和多模型集成的完整组合。

所有选择继续依据 train/dev。若要证明新的超越结论，应在新的未使用评估数据上确认，不能靠反复挑当前 test 的最优配置。本次只完成文献对照和已有结果分析，没有启动上述实验，也没有增加 preflight 或新的测试框架。
