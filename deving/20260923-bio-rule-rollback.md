## 运行前冻结协议

按 GPT Pro 的第二轮复盘，只做 `R_old + E_real + P_new`。不补跑或修改 Choice。

- 使用同一 trial24、原顺序、固定数据 commit、`jev-1.13.0`。
- 从历史 BIO r3 实际请求缓存恢复 `rules` 和 `boundary_guidance` 原文；只替换抽取 state 的这两个字段。
- 从上次缓存加载真实示例及对齐结果，不重新选样。BIO 题目、分批、解码、tokenizer、NULL 支持不变。
- 配对题目、配对 state 的新规则、阈值 0.65 均不变。仅完整模型可见请求一致时复用旧配对响应，不按 AO 字符串近似匹配。
- 新成功请求输入停止线 194,302 tokens；达到后停止下一请求，最后一请求可能小幅超过。失败请求未知消耗单列。不追加预算或删候选。
- 进入新数据验证的门槛同时满足：完整 trial Macro ≥ 历史值 +0.03（约 64.21%），Micro precision ≥ 历史值 −0.02（约 62.71%），Micro F1 ≥ 历史值（约 60.27%）。计算使用历史未舍入值。
- 若未达到门槛，停止本阶段 Jev 抽取提示探索，不追加配对消融或第二个变体。恢复到旧水平不等于取得改进。
- 本轮只判断旧规则包在固定真实示例下的作用，不归因到某一句规则，也不用于重新支持 Choice。AO pair F1 不含 VA，不是官方 cF1。

- 新成功请求 68 次，HTTP attempts 68，无重试；完整模型可见请求匹配后复用旧配对请求 4 次。
- 新输入 **131,784 tokens**，低于 194,302 停止线；新增估算费用 **$0.005535**。

- 没有 API 错误或缺失记录。

## 可支持的解释与停止决定

1. **在固定真实示例和新配对设置下，旧抽取规则包在本批数据上优于新规则包。**受控结果支持规则包变化对退化有所贡献，但仅为一次运行，没有多次采样估计波动，不能据此精确分摊全部退化。
2. **规则回退没有恢复历史 BIO 水平。**不能将剩余差距自动归因于真实示例：相对历史配置仍有示例内容/形式、BIO 题目、分批及配对提示等差异，也可能存在交互。
3. **没有证据支持替换历史基线。**本轮 Macro 38.47%、precision 42.42%、Micro F1 38.89%，均低于预先固定的继续门槛 64.21%、62.71%、60.27%。
4. **按协议结束本阶段 Jev 抽取提示探索。**不扩展 dev，不追加配对消融，不恢复 Choice，不自动启动其他模型。保留 BIO r3 作为后续替代系统的比较基线。这是资源决策，不是宣称 Jev 或 few-shot 在所有配置下无效。
