# 纯 Jev：BIO r3 + 两条 BM25 真实示例

> **归档说明（2026-09-23 清理）**：本实验的代码已原样移入 [`archive/`](archive/README.md)，不再维护，也不能在当前布局下直接运行。文中命令保留为当时的运行记录；结果以 `reports/` 中的汇总为准。

## 运行前冻结协议

用户明确允许 BM25 等非生成式方法，并要求在 dev 上测试。本轮只改变历史 BIO r3 的示例包，不延续固定标签示例的另一套 BIO 实现。

- 模型 `jev-1.13.0`，项目固定数据版本。
- 原 trial24（四语料各 6 条），以及原 dev96（八语料各 12 条）。两组分别与完全相同样本的历史 r3 缓存比较。dev 无论 trial 是否改善均运行；期间不修改配置。已有 dev 多次参与开发，不能称为独立验证。
- 每条输入从同语料 train 检索 2 条示例。BM25 k1=1.5、b=0.75；中日文字符 bigram，其他语言使用 tokenizer 的字母数字单元；同分按 ID 排序。仅用 query 原文检索，不用 query gold。
- 排除与全部 trial/dev 规范化原文重复的 train 记录，训练文本去重。不按新实验表现挑选、删减示例。
- 示例保持 r3 的四字段格式：review、tokens、aspects、opinions；不展示 BIO 标签、不展示 VA、不进行位置监督。NULL 不作为显式跨度示范。
- 仅将抽取 state 中 invented_examples 字段替换成 examples，反映真实训练记录的来源；其他规则、题目、分批、解码、pair state、阈值 0.65 和 NULL 支持原样保留。旧 r3 不支持 NULL opinion，本轮不新增。
- 直接调用原 `SpanExtractor('bio', revision=3)`，通过客户端适配器替换示例；记录实际发送的 state。
- 完整请求相同时复用历史配对响应，不仅凭 AO 字符串复用。
- trial 新输入停止线 194,302；dev 1,424,104，分别为同批历史 r3 输入的两倍。最多三条请求并发；达到停止线后不发新请求，在途请求可能造成少量超出。不根据结果调阈值或示例数。
- 同时报告 Macro/Micro AO pair F1、P/R、TP/FP/FN、跨度指标、候选配对覆盖、逐语料和输入成本。没有 VA，不是官方 cF1。
- 本轮是“合成示例包 → 检索真实示例包”的系统对照，不能单独归因到检索算法或真实示例内容。

```bash
python3 -m unittest tests.test_bio_bm25
python3 tools/probe_bio_bm25.py --split trial
python3 tools/probe_bio_bm25.py --split dev
```

原始请求与预测仅保存于忽略的 `reports/bio_bm25_20260923/{trial,dev}/cache/`。结果属于开发实验，不改 README 主表或 `logs/`，不推送 GitHub。

## 结果：trial 和 dev 均完整完成，整体未超过 r3

执行指纹 `0b7b09e56e85`。trial 24/24、dev 96/96，全部返回 `jev-1.13.0`；没有错误或重试，没有运行中调整。dev 的 96 条是已有开发样本，不是独立 holdout。

| 样本 | 配置 | Macro pair F1 | Micro pair F1 | Micro P | Micro R | TP / FP / FN |
|---|---|---:|---:|---:|---:|---|
| trial24 | 原 BIO r3 | 61.21% | 60.27% | 64.71% | 56.41% | 22 / 12 / 17 |
| trial24 | r3 + BM25 两示例 | 58.33% | 57.53% | 61.76% | 53.85% | 21 / 13 / 18 |
| dev96 | 原 BIO r3 | 45.71% | 46.40% | 50.00% | 43.28% | 87 / 87 / 114 |
| dev96 | r3 + BM25 两示例 | 44.67% | 44.74% | 47.49% | 42.29% | 85 / 94 / 116 |

相对原 r3，trial Macro −2.88 个百分点、Micro F1 −2.74 个百分点；dev Macro −1.04 个百分点、Micro F1 −1.66 个百分点。dev 少 2 个 TP，多 7 个 FP。当前点估计没有显示整体收益。

### 差异的不确定性

离线做 5,000 次成对 bootstrap，随机种子 20260923；以评论为单位，在各语料内有放回抽样，同一次抽样对两个系统使用相同评论。下表为 BM25 减原 r3 的差值，单位为百分点：

| 数据 | Macro 点估计 | Macro 95% percentile 区间 | Micro F1 点估计 | Micro F1 95% percentile 区间 |
|---|---:|---|---:|---|
| trial24 | −2.88 | [−11.38, +1.18] | −2.74 | [−9.00, +1.55] |
| dev96 | −1.04 | [−4.89, +3.74] | −1.66 | [−5.65, +2.50] |

区间跨零，不能把点估计的下降说成稳定、显著的劣势；同样没有支持稳定改善。重采样不能消除历史开发选择偏差，也不衡量模型重复调用的随机波动。

## 本轮能够得出的结论

- 在保持历史 r3 的题目、规则、分批、解码和配对方式不变时，替换为两条 BM25 真实示例没有得到整体提分；因此本轮不替换历史 r3 基线。
- 这个配置没有重现此前固定真实示例配置的大幅退化，但两轮实现的其他条件不同，不能把二者差异全部归因于 BM25。
- 结果约束的是当前检索单元、两条示例、示范格式组成的具体示例包，不能否定所有 BM25、few-shot 或纯 Jev 方法。
- 中文笔电、俄语等局部提升需要独立数据验证，不能据此直接固定逐语料选择。
- 本轮完整完成用户要求的 trial/dev 对照，没有追加更多配置、其他模型或 VA 调用。原 BIO r3 保留为比较基线。

一个针对性单测通过：检索排除重复评测文本、选择相关训练记录；仅示例包替换、其余模型请求不变；不传 query gold 或训练 VA；trace 保存实际发送内容。结果保存在 deving，不更新 README 主结果表或 logs，未 commit/push。
